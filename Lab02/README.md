# Lab 02 — Timing and software PWM

This laboratory explores timing under Python/Linux and progressively develops software-PWM applications using the on-board GPIO devices.

Complete the notebooks in the following order:

| Notebook | Main activity |
|---|---|
| [Lab02.1_Timing.ipynb](Lab02.1_Timing.ipynb) | Generate and measure periodic activity |
| [Lab02.2_Software_PWM.ipynb](Lab02.2_Software_PWM.ipynb) | Implement basic software PWM |
| [Lab02.3_PWM_LED_Brightness.ipynb](Lab02.3_PWM_LED_Brightness.ipynb) | Control perceived LED brightness and fading |
| [Lab02.4_Button_Controlled_PWM.ipynb](Lab02.4_Button_Controlled_PWM.ipynb) | Adjust PWM with push buttons |
| [Lab02.5_Dual_LED_PWM_Controller.ipynb](Lab02.5_Dual_LED_PWM_Controller.ipynb) | Build a dual-LED controller and investigate timing accuracy |

Software PWM generated by Python under Linux is not cycle-accurate. These exercises demonstrate the principle and its limitations; precise waveform generation belongs in programmable logic or dedicated hardware.

Required hardware: **Zybo legacy only**. No external components or sensors are needed.

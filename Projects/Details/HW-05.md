# HW-05 — PS-Controlled Audio Processing

[← Back to all projects](../README.md)

**Target platform:** PYNQ-Z2 preferred; Zybo Legacy if audio interface verified  
**Duration:** 4–5 weeks  
**Maximum grade:** To be specified after review

## Project Description

Software controls gain or digital filtering parameters while PL processes audio samples; audio output is demonstrated through supported codec hardware or captured sample playback.

## Minimum Implementation Requirements

Working audio sample path; configurable gain or filter; comparison of original and processed waveform; audible or saved-output demonstration.

## Project Scope and Distinction

Specify codec, connectors, drivers and audio input/output route before starting; do not assume overlays are portable between boards.

## Suggested Implementation Approach

- Identify PS software tasks and FPGA processing tasks; draw the PS–PL data-flow diagram.
- Implement or adapt the RTL/HLS/IP block and connect it using AXI4-Lite or AXI DMA as appropriate.
- Write a PS-side control, input/output and visualization application.
- Compare FPGA outputs with a software reference and demonstrate the result on the target board.

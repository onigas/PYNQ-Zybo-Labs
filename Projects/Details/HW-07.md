# HW-07 — Programmable 2D Convolution Accelerator

[Back to projects](../README.md)

**Board:** Zybo Legacy / PYNQ-Z2    
**Student deliverable:** Jupyter notebook / Python only  
**Duration:** 4–5 weeks

## Project Description and Example Demonstration

Using a programmable convolution overlay, change kernel coefficients in Jupyter for blur, sharpen and edge detection; show the three images from FPGA, without rebuilding the hardware. Requires a verified compatible overlay.

## Minimum Requirements

1. Load a precompiled, board-compatible FPGA overlay, with matching bitstream and metadata.
2. Provide usable Python controls and at least two different test input/configuration cases.
3. Show the real PL output with clear plots, tables, or audio; compare with a software reference.
4. Explain which stages run on ARM and which run in PL, including transfer overhead.
5. Document source links, dependencies, limitations and evidence of operation on the board.

**Restriction:** No hardware design, RTL, HLS, Vivado, synthesis or bitstream generation. If a suitable public overlay is not verified, the project is conditional.

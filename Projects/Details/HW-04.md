## What the Student Must Do

1. **Reproduce the author's implementation.** Download the original notebook, Python driver modules and both matching overlay files. Preserve their relative paths. Confirm the overlay loads on the **specific PYNQ-Z2 board and software image** before proceeding. If the original binary does not work on PYNQ-Z2, do not regenerate it as part of this notebook-only assignment; the instructor must first supply a compatible existing binary or reassign the project.
2. **Explain the architecture.** Identify the FFT IP in PL, the AXI DMA/FIFO interface, the AXI timer, and the Python operations in PS. Sketch a simple PS → DMA → FFT → DMA → PS data-flow diagram.
3. **Run the original FFT experiment.** Reproduce the original notebook's input generation, FFT execution and comparison with NumPy. Explain how sample lengths and data types affect the results.
4. **Extend with signals of known frequencies.** Generate (in Python) a sinusoid and a two-tone signal of a documented sample rate and FFT length. Transfer them through the available FFT driver, plot the resulting magnitude spectra, label frequency bins and compare the peak positions to NumPy FFT.
5. **Compare two DMA usage patterns.** Reproduce the author's conventional and preallocated-buffer workflows where supported by the supplied drivers. Compare complete Python-to-Python execution time at several FFT sizes; report the effect of buffer allocation and transfer overhead, not just PL computation time.
6. **Document results and limitations.** Include two spectrum plots, a timing comparison table/plot and a short explanation of differences between software and FPGA results.

## Expected Live Demonstration

In Jupyter, select a test signal and FFT size supported by the original overlay. Run the hardware FFT, display its magnitude spectrum next to NumPy FFT, and compare the two transfer approaches. Show evidence that the actual FFT overlay is loaded.

## Compatibility and Equipment

- The original article discusses PYNQ-Z1 and Arty Z7 hardware and the Zynq PS configuration for PYNQ-Z1/Z2. **Availability of the `fft.bit` file does not prove that it loads on PYNQ-Z2 unchanged.**
- Required: PYNQ-Z2 board, compatible PYNQ image, Jupyter, original `fft.bit`/`fft.hwh` and driver modules.
- External oscilloscopes, DACs or signal generators are unnecessary; input signals are generated in Python.
- Students do **not** run Vivado, regenerate the IP, or create their own hardware overlays.

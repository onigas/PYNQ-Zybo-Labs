## Project Description

Reproduce a working **digital** waveform generation and tracing example using the PYNQ-Z2 Logictools overlay. Use the **Pattern Generator** to output digital patterns on supported board I/O pins and the **Trace Analyzer** to capture and visualize them in Jupyter. Then expand the reference notebook so the user can select at least two patterns, control timing parameters supported by the existing generator, and compare the generated versus observed logic sequences.

This is **not** analog DDS, and it does not generate an audio-frequency sine-wave output. The pattern generator and trace functionality come from the supplied FPGA overlay; the student only writes/adapts Python notebook code.

## Minimum Implementation Requirements

1. Verify that the installed PYNQ image includes the **PYNQ-Z2 Logictools overlay** and that the reference code works with that image and its Python API. Do not assume every software version uses identical paths or pin maps.
2. Reproduce the reference Pattern Generator and Trace Analyzer example, documenting how the generated pattern reaches the selected I/O interface and how it is captured. If a physical pin loopback is needed, use safe 3.3 V wiring specified by the board/interface documentation.
3. Implement at least **two distinguishable digital patterns** (for example, a repeating square-wave bit pattern and a different periodic bit sequence) from notebook controls, using a timing or step configuration supported by the published Logictools API.
4. Capture and plot the output waveform. Show time steps and logic levels clearly.
5. Change a configurable pattern parameter without rebuilding any overlay, rerun capture, and compare the resulting traces.
6. Explain the roles of ARM/Python, the FPGA Pattern Generator, and the Trace Analyzer. Document limitations in timing resolution and supported I/O.

## Expected Practical Demonstration

The student loads Logictools on the PYNQ-Z2, selects pattern A or B from Jupyter, runs the hardware generator, captures the output through the trace facility, and explains the plotted digital waveforms. Show how the signal changes when a pattern or supported timing parameter is changed.

## Optional Notebook Extensions

- Simultaneous two-channel digital patterns and aligned traces.
- An automatic comparison of expected and captured bit sequences.

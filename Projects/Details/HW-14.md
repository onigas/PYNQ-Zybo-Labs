# HW-14 — ECG QRS Detection Accelerator

[← Back to all projects](../README.md)

**Target platform:** Zybo Legacy / PYNQ-Z2  
**Duration:** 4–5 weeks  
**Maximum grade:** To be specified after review

## Project Description

PS loads recorded ECG samples; PL filters and detects candidate QRS peaks; PS plots detections and computes heart rate.

## Minimum Implementation Requirements

Specified ECG dataset; one simple FPGA filtering/stage and threshold/refractory peak detection; PS visualization; annotated beats and basic evaluation.

## Project Scope and Distinction

Educational signal-processing exercise, not a medical diagnostic device; initial demonstration can use recorded data, no electrodes needed.

## Suggested Implementation Approach

- Identify PS software tasks and FPGA processing tasks; draw the PS–PL data-flow diagram.
- Implement or adapt the RTL/HLS/IP block and connect it using AXI4-Lite or AXI DMA as appropriate.
- Write a PS-side control, input/output and visualization application.
- Compare FPGA outputs with a software reference and demonstrate the result on the target board.
